# Desktop App Icon and Official Logo Refactor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refactor the official ApiDot logo SVGs with an enlarged green dot and knockout overlap, replace the desktop master icon with a macOS HIG-compliant 1024×1024 SVG, and regenerate all platform icons via Tauri CLI.

**Architecture:** Update official SVG vectors in `assets/`, construct a master `desktop/app-icon.svg` adhering strictly to Apple Human Interface Guidelines (824×824 squircle centered in 1024×1024 canvas with shadow and rim highlight), configure an `icon` script in `desktop/package.json`, and run `@tauri-apps/cli icon` to generate `.icns`, `.ico`, and PNG suites.

**Tech Stack:** SVG, Node.js, `@tauri-apps/cli` v2, Apple Human Interface Guidelines (macOS Icon Grid).

**Spec:** `docs/plans/2026-11-04-desktop-app-icon-and-official-logo-refactor-design.md`

## Global Constraints

- **Official Dot Color:** `#86BC25` verbatim.
- **Dot Dimension:** Radius `r = 22` (diameter 44 px on 160 px typography height).
- **Overlapping Treatment:** Knockout notch with 4 px gap (mask circle radius `r = 26` centered at `cx="312"`, `cy="138"` cutting into letter "I").
- **Desktop Master Icon Canvas:** `1024×1024` px viewBox.
- **macOS Squircle Dimensions:** `824×824` px at `x="100"`, `y="100"` with continuous corner radius `rx="185"`.
- **Prohibited Colors:** Old blue `#3b82f6` and old green `#10b981` must not appear in any icon or asset.

## Review Focus

1. **Transparent Margins:** The 100 px perimeter around the 824×824 squircle on the 1024×1024 canvas must remain transparent so macOS Dock does not render an opaque square box.
2. **Untracked Assets Tracking:** `assets/` must be explicitly added and tracked in git so both `api-dot-white.svg` and `api-dot-black.svg` exist in the repository.
3. **Artifact Integrity:** `icon.icns`, `icon.ico`, and `icon.png` generated by Tauri CLI must be valid, non-empty binary files.
4. **Color Strictness:** Zero occurrences of `#3b82f6` across desktop icon files and tests.
5. **Desktop Test Suite Integration:** `npm test` in `desktop/` must run the new icon validation along with all existing desktop test scripts.

const fs = require('fs');
const path = require('path');
const assert = require('assert');

const desktopDir = path.resolve(__dirname);
